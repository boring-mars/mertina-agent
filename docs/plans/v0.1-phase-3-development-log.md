### 真实服务验收（ROADMAP Done-when #3）

`uv run python examples/stop_and_resume.py --env-file .env`：

| 项 | 结果 |
|---|---|
| 第一轮 | 模型并行发出 2 个 `web_search`；工具开始时请求停止；两个结果均为中断，`interrupted=true`，`turn_exit_reason=interrupted_by_user` |
| 第一轮历史 | `user → assistant(tool_calls) → tool → tool → assistant`，以 assistant 收尾 |
| 第二轮 | 原样传回第一轮历史并追加新消息；端点接受请求，`completed=true`，`text_response(finish_reason=stop)` |
| 模型行为 | 如实说明两次搜索被中断，没有编造结果 |

结论：停止后对话可继续，模型 API 未拒绝历史，Done-when #3 达成。Done-when #2 的
各项（普通回答、工具调用、并行工具、迭代预算、重试、轮次中途停止）均有离线自动化测试覆盖。
