# Mertina Web UI 交互原型

这个分支只存放 v0.3 Web UI 的交互原型，用于讨论，和 `main` 没有共同历史，不会合并。

- `index.html`：原型本体，单文件，浏览器直接打开即可。运行状态按 v0.2 Gateway 的真实 SSE 事件名和字段用脚本回放，不连接后端。
- `screenshots/`：RFC 中引用的截图。
- `demo.mp4`：实机演示录像（约 70 秒）。

- GitHub Pages（需仓库管理员开启，来源选本分支的根目录）：https://boring-mars.github.io/mertina-agent/
- 第三方预览：https://htmlpreview.github.io/?https://github.com/boring-mars/mertina-agent/blob/web-ui-prototype/index.html
